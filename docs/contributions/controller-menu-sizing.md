# Adjustable controller-menu size

The Controller menu size slider is under **VR Settings > Interface > Menus > Controller menus**. It scales both stick-click menus from 50% to 200%; 100% preserves the original size. Pointer hit areas and the map tab use the same physical dimensions. This does not resize the independent wrist minimap.

Included in the PCVR 0.3.35 combined multiplayer build: 267/267 automated tests passed, followed by a successful complete-install flatscreen-host/VR-client gameplay test. Existing saved-setting, layout and pointer-hit-area regression coverage is retained. This is not exhaustive headset verification of every size setting.
