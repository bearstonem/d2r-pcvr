# Windows Steam artwork

Supplied by SarbaLabs for the D2R VR Unleashed Windows installer. These are the
SteamVR and Virtual Desktop PNGs from the contributor's `Artwork(4).zip`, kept
byte-for-byte. WiVRn artwork is intentionally not included.

The artwork adapts Diablo II: Resurrected promotional imagery and includes
stylized runtime marks. Blizzard and the respective runtime owners retain their
rights to their original imagery and marks; this artwork does not imply their
endorsement. It is not extracted game data and is not a claim of MIT ownership
of the underlying third-party artwork.
